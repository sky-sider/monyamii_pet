ちいさな同居人 v32 — 空腹行動の整合性修正版

【確認できた原因】
・従来の起動中の空腹増加: 0.017 / 秒 ≒ 61.2 / 時間
・従来の不在中の空腹増加: 3 / 時間（最大30）
・空腹度83超では「食べ物のありそうな場所を探しています」が毎回優先される。

【修正内容】
・ゲーム起動中の空腹増加を3 / 時間に統一。
・空腹時の食べ物探しは3分以上間隔をあけ、ほかの仕草も選べるように変更。
・旧セーブの過剰な空腹値は更新時に一度だけ最大65へ調整します（性格・思い出・所有物・服装などはそのまま）。
・従来の保存キー mofuri-pet-save-v1 を維持。

【更新方法】
更新前のゲームフォルダをバックアップし、修正版の mofuri_pet フォルダを上書きしてください。
背景、家具、プレゼント、発見ノート、お散歩など、v32の機能はそのままです。
