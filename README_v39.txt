ちいさな同居人 v39 — 背景の描き込み密度を再設計

・気に入っていただいた「森の小屋」はそのまま維持しました。
・ほかの7部屋と街・海・山のおさんぽ3背景は、旧画像の色数だけを減らすのではなく、少数の大きな形から描き直しました。
・各背景320×200ピクセル、専用のパレット、2〜3段階の明暗、大きな窓や特徴的な地形を優先。
・おへやの下部は家具とペットのための余白を確保。
・おさんぽは既存の花壇・看板・ベンチ・波・貝殻・小川などの探索ポイント座標を維持。
・天気演出の窓座標は新背景に合わせて更新。
・既存の家具画像、ペット画像、UI、セーブキー、バックアップ形式は変更していません。
・ブラウザのキャッシュ対策のため、背景画像の参照URLに v39-art を付与。

更新するときは「ノート → 保存」でJSONバックアップを作り、フォルダをバックアップしたうえで一式を上書きしてください。
