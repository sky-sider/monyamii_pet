ちいさな同居人 v40 ― 背景画風統一版

変更内容
・「森の小屋」をそのまま基準に、残り7部屋とおさんぽ3種類を320×200px・各64色のドット絵に描き直しました。
・全背景の色の粒度と輪郭を揃えるために、縮小はエリア平均(Box)、色数削減はディザなしの中央値法を使用しています。
・家具・ペット・お土産・UIのスプライト画像、ゲームの保存キーとデータ形式は変更していません。
・新背景の窓の形・位置に合わせ、室内の天気演出のクリッピング範囲を更新しました。
・探索中の行動対象が背景にもあるよう、街のベンチ、海の貝殻・流木、山のきのこ・小川など小さな目印を背景に追加しました。
・画像キャッシュが古い背景を表示しないよう、画像参照のバージョン番号を更新しました。

更新方法
・まずゲームの「ノート → 保存」からJSONバックアップを書き出してください。
・ZIP内の mofuri_pet フォルダを、現在のゲームフォルダと差し替えます。
・GitHub Pagesなどにアップロードしている場合は、assets/rooms / assets/walks / index.html / script.jsを更新してください。
・localStorageに保存したゲームデータは、同じURL・同じドメインでゲームを開けば従来どおり利用できます。

補足
・以前の背景はバックアップしたゲームフォルダから復元できます。
