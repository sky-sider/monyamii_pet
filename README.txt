ちいさな同居人 v4 — おへやと好奇心
=======================================

【はじめかた】
1. ZIPファイルを展開します。
2. mofuri_pet フォルダ内の index.html をChromeやEdge等で開きます。
3. 「おへやのもの」からアイテムを選び、部屋をタップして配置します。
4. ペットが自分で近づき、眺めたり、遊んだり、休んだりする様子を観察します。

【アイテム】
・毛糸玉：遊ぶ／遠くから眺める
・クッション：くつろぐ／うとうとする
・きらきら小石：眺める／小さな石をつつく
・鉢植え：匂いや葉っぱを調べる

毛糸玉とクッションは最初から部屋にあります。
小石と鉢植えはメニューから配置できます。
同じ種類のアイテムは1個までです。配置済みを選ぶと移動できます。
初期版では床の横方向だけを指定できます。
配置中に同じボタンを押すか「配置をやめる」で取り消せます。
PCではキャンバスにフォーカスして左右矢印＋Enterで配置できます。

【ペットの行動】
・興味がある時は、置かれたアイテムの近くへ自分で歩きます。
・性格、好み、疲労、警戒、過去に触れた経験から反応が変わります。
・一度調べたアイテムを何度も連続で選ばないようにしています。
・同じものを繰り返し選ぶようになると、小さな発見が追加されます。
・プレイヤーの交流ボタンを押すと、家具への行動を中断して反応します。
・ペットの内部の数値はゲーム上に表示されません。

【既存ゲームから更新するとき】
1. 念のため現在のフォルダのバックアップを作ってください。
2. v4 の index.html / style.css / script.js / assets を既存の場所に上書きします。
3. いつも使っているブラウザと同じURL・同じ保存領域で開いてください。
   v1-v3 と同じ保存キー mofuri-pet-save-v1 を使用します。
   ただし file:// の保存領域はブラウザやファイルパスによって変わるため、
   場所を変えると以前のペットを引き継げない場合があります。
4. 「最初からやり直す」は保存データを消去します。ご注意ください。

【テスト】
JavaScriptの構文、ドット絵画像の寸法、操作と自律行動のブラウザ模擬テスト、
セーブデータ互換性、およびスマホ・PCサイズの表示を確認しました。
ブラウザ模擬テストはリソースを埋め込んだ環境で実施したため、
実際のローカルファイル環境での動作保証ではありません。
