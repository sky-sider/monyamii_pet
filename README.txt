ちいさな同居人 v15 — ふわふわ、そっとなでる
========================================

【起動方法】
このフォルダにある index.html をブラウザで開きます。
index.html / script.js / style.css / assets の位置は変更しないでください。
スマホでのURL公開には従来どおり GitHub Pages などを利用できます。

【v15 新機能：なでる】
・「いっしょ」画面のペット本体をタップすると、なでることができます。
・ペットの体を指で横にやさしくなぞると、なでる動作として認識します。
・「そっとなでる」ボタンでも操作できます。キーボードならキャンバスに
  フォーカスして Enter / Space でもなでられます。
・眠っているときは起こさず体を少し伸ばし、安心しているときはふわっと
  伸びたり跳ねたりします。警戒している子はそっと距離をとることもあります。
・なでられた経験による好みが保存されます。ときどき、なで終わったあと
  もう一度近づいて「もっとなでて」とおねだりすることもあります。
・おねだりが来たら同じ操作で応えられます。無視してもペナルティはありません。
・初めてなでた日、おねだりしてくれた日、応えた日などが発見ノートに残ります。
・交流成功時は「ふれあいポイント」を獲得できます（連打対策・1日上限あり）。

【画面メニュー】
・いっしょ：ペットの様子を見る、名前を呼ぶ、食べ物を置く、遊びに誘う、近づく、なでる
・おへや：洋風・和風・可愛い・サイバーの切り替え、おもちゃや家具の配置、痕跡の片づけ
・おめかし：ふれあいポイントで頭飾りを解放、着け替え、ペットの自主着せ替え設定
・ノート：お気に入りの場所、なでられた記憶、思い出、秘密の習性、発見ノート

【家具の配置】
「おへや」でアイテムを選ぶと「いっしょ」に移動します。
床をタップして置いてください。配置中はなでる操作になりません。
間違えたときは「やめる」で配置モードを解除できます。

【旧バージョンからのアップデート】
既存のファイルをバックアップしてから、v15 のファイル一式を上書きしてください。
同じブラウザ・同じサイトURLなら旧セーブを利用できる設計です。
保存キー mofuri-pet-save-v1 は変更していません。
ただしブラウザの file:// 保存領域はフォルダの場所によって変わる場合が
あります。GitHub Pages では従来のURLで更新することをおすすめします。
過去の「なでられた日」はv14以前に記録されていないため推測で追加しません。

【同梱素材】
assets/rooms : 4種類のドット絵背景
assets/sprites : ペットの動作・色違い
assets/items : おもちゃ・家具
assets/headwear : 10種類の頭飾り

【その他】
ペットの感情パラメータは非表示で、仕草や行動から判断できます。
ポイントや記録はゲーム内・ブラウザ内のものです。外部送信は行いません。
