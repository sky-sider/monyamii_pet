ちいさな同居人 v20 — お散歩での行動拡張

【使い方】
1. ZIPを解凍して、mofuri_pet フォルダを開きます。
2. index.html をブラウザで開きます。
3. 「いっしょ」画面の「おさんぽに出かける」から、街・海辺・山の小道を選びます。
4. 何も操作せず見守るか、気になる場所をタップ／探索先ボタンで誘います。
5. ペットをタップまたは優しくなぞると、散歩中もなでられます。
6. いつでも「おうちに帰る」で帰宅できます。

【v20で追加した機能】
・3か所×4対象×3反応＝36通りのお散歩行動。
・天気・季節、性格、疲れやすさ、対象への慣れと好みで行動選択が変化します。
・海辺が好きでも波は苦手、など、探索対象ごとの学習記録を別々に保存します。
・花びら／砂／水しぶきなど、既存のドット絵に重ねる小さな演出を追加しました。
・新しい特徴的な行動、好きそうな対象、慎重になる対象は「発見ノート」に記録されます。
・発見ノートの日時は実際に見た出来事だけを記録します。
・おみやげは以前と同じく、お散歩1回で最大1個です。

【引き継ぎ方法】
・現在のゲームフォルダは必ず別の場所にバックアップしてください。
・新しいZIP内の index.html、style.css、script.js、assets フォルダをすべて上書きします。
・ブラウザでセーブデータを引き継ぐには、同じURL／同じ保存場所から開いてください。
・ブラウザの保存領域(localStorage)が異なるURLや端末間では自動移行しません。
・v19までの性格、家具、頭飾り、ポイント、既存の思い出、探索回数は保持します。
・v20で追加した「対象別の好みと行動」は、アップデート後に実際に行動した分から学習します。

【内容物】
index.html 画面構成
style.css 表示・スマホ用スタイル
script.js ペットの行動とデータ管理
assets/ ゲームで使うドット絵素材

※ ゲームはブラウザ内で完結し、実際の天候APIやログインは不要です。
※ ペットの感情の内部数値はプレイヤーには表示しません。
