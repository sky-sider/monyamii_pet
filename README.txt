ちいさな同居人 v12 — おめかし屋さん

起動: index.html をブラウザで開くか、GitHub Pagesへ一式をアップロード。

追加要素: 10種類の透過ピクセル頭飾り (assets/headwear/*.png)、ふれあいポイント、購入/装着/解除。
初期解放: ちいさな葉っぱ（0pt）。他はポイントをためて解放します。
ポイント: 見守り +2（2分間隔）、呼びかけ応答 +5、食事成功 +7、遊び成功 +10、近づくのを受け入れた +5〜7、誘いに応える +12。
同じ行動からポイントが入るのは45秒に1回まで（見守りは2分）。1日100pt上限。
警戒されたり寝ていたりした場合など、交流が成立しなかったときは付与しません。
気に入らないときは装飾を外せます。何度着脱してもポイントは減りません。
新しいポイント・購入履歴・装着状態はこれまでのセーブに追加して保存します。
古いデータからは0pt、無料の葉っぱが解放された状態で始まります。

フォルダやファイル名は変更しないでください。背景4種・家具・ドット絵の従来機能はそのままです。
