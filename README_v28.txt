ちいさな同居人 v28 — ちいさな贈りもの

● 既存ゲームとセーブデータは引き継ぎます。保存キーは mofuri-pet-save-v1 のままです。
● お散歩で拾った6種類のお土産がプレゼントの対象になります。
● これまでに拾った品は初回アップデート時に在庫として引き継ぎ、二重加算しません。
● プレゼントはお部屋でまれに発生する自発的なお誘いです。
● 受け取った場合だけ在庫が1つ減り、発見ノートの「贈りもの」と「もらった宝物」に記録されます。
● そっと見守る・放置・途中終了は在庫を減らしません。1日2個まで受け取れます。
● 将来のお土産追加: script.js の SOUVENIR_CATALOG に新種IDを追加し、WALK_DESTINATIONS の target.itemId と
   対応する assets/souvenirs/<id>.png を用意するとプレゼント管理に反映されます。
   新しい探索対象自体を増やす場合は WALK_BEHAVIORS に対応する行動も追加してください。
● 更新方法: 現在のフォルダをバックアップした後、ZIP内の mofuri_pet 以下をすべて上書き。
   今回追加された assets/souvenirs/ も必ずコピーしてください。
