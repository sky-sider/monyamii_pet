ちいさな同居人 v34 — セーブデータのバックアップ

■ 操作
1. ノート > 保存 を開きます。
2. 「バックアップを書き出す」でJSONファイルをダウンロードします。
3. 読み込むときは「バックアップファイルを選択」でJSONを選びます。
4. 名前・日数・おへや・保存日時を確認し、「この記録を復元する」を押します。
5. 確認ダイアログで承認すると、現在の記録を置き換えてゲームを再読み込みします。

・セーブキー mofuri-pet-save-v1 は変更していません。
・旧v33形式のセーブデータ(JSON)にも対応します。
・読み込み時はチェックサムとデータ形式を確認します。
・復元直前の記録はブラウザ内に1件退避します。
・ほかのブラウザや端末に移す場合はJSONファイルを手元に保存し、移行先で読み込んでください。
・バックアップファイルは自分で安全な場所に保管してください。
・ブラウザでダウンロードをブロックされる場合は、ブラウザの設定をご確認ください。
・v33のペット・家具・宝物・おさんぽ・思い出・A/Bタイプなどの仕様は変更していません。
