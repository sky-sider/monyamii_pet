ちいさな同居人 v29 — おさんぽのおみやげ 18種類

■ 新しく増えた12種類
街: 四つ葉のクローバー、星形の花びら、透きとおるビー玉、小さな古い鍵
海: くるくる貝、真珠色の小粒、青いシーグラス、琥珀色のシーグラス
山: まつぼっくり、しましま木の実、小鳥の羽根、赤いもみじ
既存6種類と合計で18種類。

■ 遊び方
「いっしょ」→「おさんぽ」で街・海・山に出かけてください。
同じ探索対象でも、見つかる宝物の種類が少しずつ変わります。
天気・季節・好みで出やすさが変わりますが、特定の季節でしか取れない品はありません。
お土産は1回のお散歩で最大1個。見つけたものは部屋に持ち帰り、v28のプレゼント機能にも対応。
「おさんぽ」画面の「おみやげ図鑑」を開くと、見つけた種類と未発見の数を確認できます。

■ 大切なセーブデータ
保存キー mofuri-pet-save-v1 は変更しません。v28以前の6種類の在庫・発見履歴・贈りもの履歴を保持します。
今回追加した12種類は、新規のIDとして新しく扱うため、古いデータから突然発見済みになることはありません。

■ 将来の追加方法
script.js の SOUVENIR_CATALOG に新しいIDと定義を加えて、対応する assets/souvenirs/<ID>.png を置きます。
既存の探索対象と同じ location と targetId を指定すれば、その対象からの抽選候補に自動追加されます。
rarity (1/2/3)、dropWeight、weatherBoost、seasonBoost で見つかりやすさを調整できます。
探索対象そのものを増やすときだけ、WALK_DESTINATIONS と WALK_BEHAVIORS の追加が必要です。

■ 更新方法
現在のゲームフォルダをバックアップし、ZIP内 mofuri_pet フォルダ以下をまとめて上書きしてください。
assets/souvenirs 内の画像も必ずコピーしてください。同じブラウザ・URLで起動すると既存のセーブを利用できます。
