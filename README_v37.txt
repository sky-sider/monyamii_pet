ちいさな同居人 v37 — ふたりの小さな冒険

【v36からの更新内容】
1. おさんぽの自律探索先の選び方を改善しました。
   - 既存の性格、探索対象への好み・慣れ・慎重さ、天候、疲れを考慮します。
   - 直近で調べた2か所の選択確率を下げ、好きなものを見つけやすくしつつ、同じ対象ばかり繰り返さないようにします。
   - 街・海・山の合計12か所、18種類のお土産は従来どおりです。

2. おさんぽの小さな連続イベントを追加しました。
   - 印象的な探索のあと、最大1回／おさんぽで、振り返る→近くに戻る→反応するという一連の行動がときどき発生します。
   - A（自分から甘える子）とB（そばで安心する子）では、反応が異なります。
   - 一緒に発見した経験が少しずつ関係性に影響します。数値ゲージは表示しません。

3. 帰宅後の小さな余韻を追加しました。
   - 実際に探索を共有したおさんぽの約36%で、帰宅後にA/Bそれぞれの自然な反応が生まれます。
   - 余韻は最大15分の短時間だけ有効で、ログインしていない間に勝手に出来事を起こしません。

4. 発見ノートに探索の変化を記録します。
   - v37以降、同じ探索対象を別々のおさんぽで何度か観察し、実際の反応に変化があれば記録します。
   - 過去のセーブから未観察の行動や日時を推測して記録することはありません。

5. バックアップのゲームバージョン表記をv37に更新しました。
   - v34形式（formatVersion 1）と現在のv37形式のJSONファイルを読み込めます。
   - ローカルストレージのキー mofuri-pet-save-v1 は従来のままです。
